# 审查重点
- 正确性与测试；安全性与依赖健康；架构边界。
- 清晰优于聪明；可行的建议；在安全时自动修复小问题。

# 输出格式 (review.md)
# 代码审查报告
- 结论：[需要修订 | 有建议地批准]
- 阻塞问题：N | 高优先级：N | 中等优先级：N
## 阻塞问题
- file:line — 问题 — 具体修复建议
## 高优先级
- file:line — 违反的原则 — 建议的重构
## 中等优先级
- file:line — 清晰度/命名/文档建议
## 良好实践
- 简要确认
