# 学习路径

系统化的学习计划，帮助你从零开始掌握 Claude Code。

## 🎯 学习目标

完成本学习路径后，你将能够：

- ✅ 熟练使用 Claude Code 进行日常开发
- ✅ 构建自己的命令、技能和子智能体
- ✅ 设计高效的开发工作流
- ✅ 应用最佳实践到实际项目

## 📅 3周学习计划

### Week 1: 理论基础 📚

**目标**: 理解核心概念和基础操作

#### Day 1-2: 入门准备
- [ ] 安装 Claude Code
- [ ] 完成 [快速开始](./getting-started.md) 教程
- [ ] 运行天气工作流示例
- [ ] 了解基本命令（/help、/model、/context）

#### Day 3-4: 核心概念
- [ ] 学习 [8大核心组件](./concepts.md)
- [ ] 理解命令、技能、子智能体的区别
- [ ] 阅读 [CLAUDE.md 最佳实践](/best-practice/claude-memory)
- [ ] 创建第一个 CLAUDE.md 文件

#### Day 5-7: 视频学习
- [ ] 观看 [Y Combinator 访谈](/videos/claude-boris-y-combinator-17-feb-26)
- [ ] 观看 [The Pragmatic Engineer 访谈](/videos/claude-boris-pragmatic-engineer-04-mar-26)
- [ ] 阅读 [Boris 的 13 条技巧](/tips/claude-boris-13-tips-03-jan-26)
- [ ] 记录对你有用的要点

**周末检查点**: 能够解释 8 大核心组件，知道何时使用命令、技能、智能体

---

### Week 2: 实践应用 💻

**目标**: 动手实践，构建自己的配置

#### Day 8-9: 命令实践
- [ ] 阅读 [命令最佳实践](/best-practice/claude-commands)
- [ ] 查看 [命令实现示例](/implementation/claude-commands-implementation)
- [ ] 创建 3 个常用命令（测试、部署、代码审查等）
- [ ] 测试命令是否正常工作

#### Day 10-11: 技能实践
- [ ] 阅读 [技能最佳实践](/best-practice/claude-skills)
- [ ] 查看 [技能实现示例](/implementation/claude-skills-implementation)
- [ ] 创建 1-2 个技能（项目特定知识）
- [ ] 体验渐进式展示模式

#### Day 12-14: 子智能体实践
- [ ] 阅读 [子智能体最佳实践](/best-practice/claude-subagents)
- [ ] 查看 [子智能体实现示例](/implementation/claude-subagents-implementation)
- [ ] 创建 1 个功能特定的子智能体
- [ ] 配置钩子系统（可选）

**周末检查点**: 在自己项目中有可用的命令、技能和智能体

---

### Week 3: 工作流优化 🚀

**目标**: 建立完整工作流，提升团队效率

#### Day 15-16: 工作流设计
- [ ] 学习 [编排工作流](/workflows/orchestration)
- [ ] 研究 [10大工作流对比](/workflows/comparison)
- [ ] 选择适合你的工作流模式
- [ ] 设计团队工作流架构

#### Day 17-18: 高级功能
- [ ] 配置 [MCP 服务器](/best-practice/claude-mcp)
- [ ] 探索 [增强功能](/best-practice/claude-power-ups)
- [ ] 学习 [CLI 启动标志](/best-practice/claude-cli-startup-flags)
- [ ] 尝试高级特性（智能体团队、定时任务等）

#### Day 19-21: 项目整合
- [ ] 将学到的知识应用到实际项目
- [ ] 编写团队的 CLAUDE.md 规范
- [ ] 创建共享的技能库
- [ ] 建立代码审查工作流
- [ ] 收集团队反馈，持续优化

**最终检查点**: 有完整的 Claude Code 配置，团队认可并使用

## 💡 学习技巧

### 高效学习方法

1. **理论与实践结合** 📚➕💻
   - 看完理论立即实践
   - 不要只看不做
   - 在真实项目中应用

2. **问题驱动学习** 🎯
   - 带着问题学习
   - 遇到问题查文档
   - 解决实际需求

3. **记录和总结** 📝
   - 记录有用的技巧
   - 总结最佳实践
   - 分享给团队

4. **社区互动** 👥
   - 参与讨论
   - 提问和回答
   - 贡献经验

### 常见陷阱

❌ **跳过基础** - 直接上手高级功能  
✅ **打好基础** - 从核心概念开始

❌ **过度工程化** - 一开始就构建复杂系统  
✅ **循序渐进** - 从简单命令开始

❌ **只学不练** - 只看文档不实践  
✅ **边学边练** - 立即应用到项目

❌ **孤立学习** - 独自摸索  
✅ **社区互动** - 参与讨论和分享
